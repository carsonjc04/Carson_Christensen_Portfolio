# Carson Christensen — Portfolio

Single-page portfolio built with Next.js (App Router) and Tailwind CSS v4.

## Develop

```bash
npm install
npm run dev
```

## Edit content

All copy lives in `src/data/content.ts`. To show project links, set `github` / `live` on a project.

## Résumé

Place your résumé at `public/resume.pdf`. Both download buttons point there.

## Deploy

Import the repo in Vercel. No configuration needed.
